Política de Privacidade

Central de Produção — ferramenta interna da equipe do canal Cine Nostálgico. Atualizada em 9 de novembro de 2026.

O que o programa acessa

Quando um membro da equipe conecta a própria conta Google, o programa pode acessar, somente com a permissão dada na tela do Google: os dados dos canais do YouTube dessa conta (lista de vídeos, títulos, descrições, tags, playlists e estatísticas de desempenho, sem dados de receita), arquivos do Google Drive, planilhas do Google Planilhas e documentos do Google Docs que a pessoa escolher usar, e, se autorizado, o envio de vídeos ao YouTube em nome dela.

Como os dados são usados

Os dados são usados apenas para as funções do programa: gerar planilhas de estatísticas, preparar títulos, descrições e palavras-chave, e publicar vídeos quando a pessoa pedir. Não usamos os dados para publicidade e não os vendemos.

Onde os dados ficam

Tudo fica no computador de quem usa o programa. A chave de acesso do Google é guardada criptografada pelo próprio Windows. Não temos servidor: o programa não envia os dados para nós nem para terceiros. Para gerar textos, o programa pode usar o Claude (Anthropic) pela assinatura da própria pessoa, enviando apenas o texto necessário para aquela tarefa.

Como remover o acesso

A pessoa pode desconectar a conta no próprio programa (botão "Desconectar") ou a qualquer momento em myaccount.google.com/permissions. Ao desconectar, a chave é apagada do computador.

Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. O uso dos dados do YouTube segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.
